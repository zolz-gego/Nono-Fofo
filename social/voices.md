# Character voices (ElevenLabs)

Make each voice **once**, save it in ElevenLabs under the name shown, and use
it for every video so the brothers always sound the same.

Model for all lines: **Eleven v3**. Stability: **Creative** (most expressive;
switch to **Natural** if a take sounds off). Language: Arabic.

---

## Nono (نونو), 9 years old

Save the voice as **`Nono`**.

**Voice Design prompt** (ElevenLabs → Voices → Create → Voice Design):
```
Cartoon voice for an animated kids' show: a cheerful 9-year-old Egyptian boy speaking Egyptian Arabic with a natural Cairo accent. Bright, slightly high-pitched, energetic and fast-talking, always smiling, a little breathless as if he just ran in. Playful and confident, giggles easily. Clean close-mic studio recording, no background noise, no music.
```
Preview text to paste in the designer:
```
[excited] أهلاً أهلاً! أنا نونو! [giggles] أنا بحب أجري وبحب الكورة أوي... يلا بينا!
```

If Voice Design won't make a child-like voice, pick a "young cartoon boy" voice
from the Voice Library and check it says the preview text with an Egyptian
accent.

## Writing lines for v3 (for Claude)

- Tags go in square brackets before the words they color, in English:
  `[excited]`, `[happily]`, `[proudly]`, `[curious]`, `[thoughtful]`, `[whispers]`,
  `[shouting]`, `[surprised]`, `[sad]`, `[giggles]`, `[laughs]`, `[gasps]`, `[sighs]`.
  Sound tags like `[giggles]` go where the sound happens.
- One or two tags per line is plenty; more makes v3 overact.
- `...` makes a small pause, `!` adds energy, `؟` lifts the end.
- Write Egyptian Arabic the way it's spoken (بحب، أوي، يلا بينا، عايز، فين), not MSA.
- Short lines (1–8 words). One line = one scene = at most 4–5 seconds.
