# Nono & Fofo: logo prompts

For Gemini (Nano Banana / Imagen), ChatGPT images, Midjourney and similar tools.

How to use:
1. **Always attach `design/reference/nono-fofo-approved.webp`** so the brothers stay on-model.
2. Try each concept 3 or 4 times and keep the best one.
3. **Generate without text.** Image tools usually garble Arabic and Coptic letters. We add the name (English + نونو وفوفو) and any real Coptic letters afterwards as vector text in the right fonts.
4. Send me the winner and I'll clean it up as an SVG and export the app icon sizes.

## Tips

- **If the faces drift off-model:** add "keep exactly the same faces, hair and skin tone as the attached reference" and regenerate.
- **If it comes out too detailed for an icon:** add "simpler shapes, fewer details, thicker outlines, icon style".
- **If the tool insists on adding text:** add "absolutely no text, no letters, no words anywhere".
- **Transparent background:** keep the plain background and remove it with remove.bg or Canva, as with the poses.
- **Coptic letters in the logo:** if you want a real letter (for example Ⲁ on the book), leave a blank spot on the page and I'll place it in the Avva Shenouda font, so it's correct.
