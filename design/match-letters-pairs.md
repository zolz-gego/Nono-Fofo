# Match the letters: pairs to review

Each row of the game pairs one Coptic letter with what it sounds like **in that word**. These pairs are saved as `sounds` in `app/assets/content/games/letter_puzzle.json` (same words as the Letter puzzle). Only lengths 3–7 are listed (the ones the picker offers).

## Rules I used (please confirm)

1. **Arabic, written letter:** the pair is the word's own letter, so ⲕ = ق in قبة, ⲥ = ص in صليب, ⲧ = ط in طول, ϩ = ح in لحن, ⲁ = ة / ى / آ / أ when the word writes it that way.
2. **Arabic, unwritten vowel** (marked ⚠): when the word has no letter for a Coptic vowel (رب = ⲣⲁⲃ), the pair is the letter's own sound: ⲁ → ا, ⲉ ⲏ ⲓ → ي, ⲟ ⲱ → و. ⲩ after ⲟ (نور = ⲛⲟⲩⲣ) → و.
3. **Two rows with the same answer** (ⲏ and ⲓ both ي, ⲟ and ⲱ both و, ⲕ and ⲭ both ك): a line to either one counts as right.
4. **ئي** (ميخائيل، رافائيل، جبرائيل) is shown as plain ي.
5. **English:** each letter's Latin sound from the letters data: ⲁ a, ⲃ b (v in Love, Visa, Oven, Heaven), ⲅ g, ⲇ d, ⲉ e, ⲍ z, **ⲏ y**, ⲑ th, ⲓ i, ⲕ k, ⲗ l, ⲙ m, ⲛ n, ⲝ x, ⲟ o, ⲡ p, ⲣ r, ⲥ s, ⲧ t, ⲫ f, ⲯ ps, ⲱ o, ϣ sh, ϥ f, ϧ kh, ϩ h, ϫ j (g in Gabriel), ϭ ch, ϯ ti. Shenouda's ⲩ = u.

Tell me any word to change as `word: letter=sound` (e.g. `رب: ⲁ=َ`).
