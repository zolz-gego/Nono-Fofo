# ElevenLabs prompts: copy & paste

Every prompt below is complete, so paste it as-is. Save each result with the
file name shown, then run `tools/.venv/bin/python tools/audio/process_audio.py`.

**Licence:** on the **free** plan, ElevenLabs music needs credit to
elevenlabs.io and free-plan output is meant for non-commercial use. For the
published app, generate the final versions on a **paid** plan (Starter is
enough). Free is fine for trying prompts out.
